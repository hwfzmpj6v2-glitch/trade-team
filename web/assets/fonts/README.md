# Písma

Obě písma jsou hostovaná přímo v tomto repu, ne z CDN. Stránka tak nedělá
žádný požadavek na cizí server a návštěvníky nikdo netrackuje.

- **Anton** — displejové písmo pro velké nadpisy. Licence SIL OFL 1.1, viz `OFL-Anton.txt`.
- **Barlow Condensed** — mezititulky, popisky, tlačítka. Licence SIL OFL 1.1, viz `OFL-BarlowCondensed.txt`.

Soubory jsou ořezané na znakové sady `latin` a `latin-ext`, takže obsahují
českou diakritiku a nic navíc. Dohromady zabírají zhruba 85 kB.

Běžný text stránky používá systémové písmo — nestahuje se nic dalšího.
